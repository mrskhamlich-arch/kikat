# Quick Start Guide

## 🚀 Getting Started (No Installation Needed!)

### Step 1: Open Your Site
1. Open `index.html` in any web browser
2. See your landing page with hero section, links, and social media buttons

### Step 2: Customize Everything
1. Open `admin.html` in a browser tab
2. Sign in with password: **kitkat09**
3. You now have access to all customization features

---

## ✨ Feature Walkthrough

### Basic Settings
- **Site Title**: Main heading that displays with emoji
- **Tagline**: Secondary text under title
- **About Section**: Large text block at bottom

### Fonts & Emojis
1. **Select Font**: Choose from Inter, Poppins, Georgia, Monospace, Cursive
2. **Click Emoji**: Choose from 20 emojis to add to title (displays before title text)

### Colors & Theme
1. **Primary Color**: Use color picker or type hex code (#0b69ff = blue, #ff5d5d = red, etc.)
2. **Background Color**: Change site background color
   - Both color inputs sync with each other automatically
   - Changes apply instantly to index.html

### Video
- **YouTube URL**: Paste `https://youtube.com/watch?v=dQw4w9WgXcQ`
- **Direct Video URL**: Paste any MP4/WebM URL
- **Upload File**: Upload MP4 file directly (stored in browser)
- Video displays in "Featured Video" section on index.html

### Media Gallery
- **Add Image from URL**: Paste any image URL and click Add
- **Upload Image File**: Click upload to add image file
- All images display as thumbnails in admin, full gallery on index.html
- Click X button to delete any image

### Links & Social
- **Add Link**: Name + URL (displays as large button)
- **Add Social**: Name + URL (displays as circular icon)
- Click Delete to remove any link

## 💡 Tips & Tricks

### Color Codes
- Blue: `#0b69ff` (default)
- Red: `#ff5d5d` (danger)
- Green: `#10b981` (success)
- Dark: `#1e293b`
- Light: `#f8fafc`

### YouTube URL Formats (All Work!)
- `https://youtube.com/watch?v=dQw4w9WgXcQ`
- `https://youtu.be/dQw4w9WgXcQ`
- `https://www.youtube.com/watch?v=dQw4w9WgXcQ`

### File Upload Sizes
- Images: Up to ~5-10MB (stored as base64 in browser)
- Videos: Up to ~50MB (stored as base64 in browser)
- Note: Very large files may be slow to save/load

### Data Storage
All your data is stored in your browser's localStorage
- Data persists even after closing browser
- Data is local to this browser/device
- To backup: Export/save the admin panel data manually
- To reset: Clear browser cache/localStorage

## 🔧 Troubleshooting

### "Changes not showing in index.html?"
- Refresh index.html page
- Make sure admin.html and index.html are in same folder
- Check browser console for errors (F12 → Console)

### "Can't sign in to admin?"
- Password is: `kitkat09`
- Make sure you typed it correctly
- Check caps lock is off

### "Video not playing?"
- YouTube videos must be public (not private/unlisted)
- Direct video URLs must be accessible
- Some URLs may have CORS restrictions

### "Images not showing?"
- Direct image URLs must be publicly accessible
- Some image URLs may have hotlink protection
- File uploads should work locally

### "Colors not changing?"
- Both admin and index must be using same localStorage
- Try refreshing index.html
- Check hex codes are valid (# followed by 6 characters)
